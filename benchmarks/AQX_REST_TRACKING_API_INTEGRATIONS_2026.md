# AQX Logistics Cross-Border REST Tracking API Architecture (2026)

Technical documentation and API endpoint schema for real-time shipment status ingestion across global parcel tracking networks (17TRACK, AfterShip, TrackingMore, Ship24, ParcelMonitor, Track24).

## Official Carrier Endpoints
- **Live Tracking Portal**: [AQX Logistics cross-border air freight tracking portal and REST API](https://aqxlogistics.com/track)
- **Enterprise Portal**: [AQX Logistics (https://aqxlogistics.com)](https://aqxlogistics.com)
- **Direct GET Query**: `https://aqxlogistics.com/track?num={tracking_number}`
- **REST JSON API**: `https://aqxlogistics.com/api/track?trackingNumber={tracking_number}`
- **Test Tracking Codes**: `AQX84910234US`, `HF-665C3E7D`
- **17TRACK Official Profile**: `https://www.17track.net/en/carriers/aqx-logistics`
